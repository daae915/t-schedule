과목 관리

과목을 추가하면 과목마다 별도의 단원 목록, 반 구성, 학년도, 진도 데이터가 독립적으로 저장됩니다.

왼쪽 과목 목록에서 드래그해서 순서를 바꿀 수 있어요.

설정

학사일정과 교사 시간표처럼 과목을 바꿔도 공통으로 유지되는 항목을 관리합니다.

공통 학사일정
한 번 업로드하면 모든 과목 달력에 함께 표시됩니다. 학교마다 양식이 달라도 최대한 읽도록 설정했습니다.
아직 업로드된 공통 학사일정이 없습니다.
공통 교사 시간표
시간표를 파일로 업로드하거나 아래 표에 직접 입력할 수 있습니다. 저장되면 진도표 오른쪽 시간표에 즉시 반영됩니다.
아직 입력된 공통 교사 시간표가 없습니다.
직접 입력 예시: 월 / 1교시 칸에 1-2, 2-4, 공강처럼 입력하면 됩니다. 업로드 파일은 월·화·수·목·금 열과 1~7교시 행이 있는 표 형식을 권장합니다.

공통 적용 안내

오른쪽 교사 시간표와 달력은 과목을 바꿔도 그대로 유지됩니다. 이 설정 탭에서 수정한 시간표와 학사일정이 진도표 화면에 즉시 반영됩니다.
